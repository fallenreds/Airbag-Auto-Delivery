# airbagAD

Django backend + aiogram Telegram bot + React frontend (подмодуль `frontend/`).

## Git workflow

Действуют глобальные правила ветвления (`~/.claude/CLAUDE.md`) с уточнениями для этого репозитория:

- Основная ветка этого репозитория — **`v2`**. `develop` не используется.
  `master` заброшен: последний коммит — 22.03.2026, и он безвозвратно разошёлся с `v2`
  (19 коммитов есть только в `master`, ~280 — только в `v2`). Ветвиться от `master` нельзя.
- Ветвиться всегда от актуального `origin/v2`.
- Принятые в репозитории префиксы веток: `feat/`, `fix/`, `chore/`, `feature/AIRBAG-NN-<описание>` (для задач с тикетом).
- Подмодуль `frontend/` — отдельный репозиторий, и его основная ветка — **`main`** (не `v2`, хотя
  `.gitmodules` всё ещё указывает `branch = v2` — устаревшая метаинформация; во фронтенде `v2` уже
  влит в `main`). Правило действует и там: изменения во фронтенде идут через отдельную ветку.
- Хук [.claude/hooks/pre-bash.sh](.claude/hooks/pre-bash.sh) блокирует прямые коммиты и push на
  `master`/`main`/`develop`. Внимание: **`v2` в этом списке нет**, поэтому реальный ствол хуком не
  защищён — следить за этим приходится вручную.

Дополнительные git-ограничения того же хука:

- `git push --force` без `--force-with-lease` — запрещён.
- `git commit --no-verify` — запрещён (не обходить pre-commit, а чинить причину).
